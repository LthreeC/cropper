# 白边裁剪工具 (White Border Cropper)

一款专业的白边自动检测与裁剪工具，专为需要批量处理 PPT 幻灯片、PDF 文档、图片素材的用户设计。告别繁琐的手动裁剪，一键去除多余白边，让你的内容更加紧凑、专业。

**关键词**: PPT去白边、PDF裁剪、图片批量裁边、幻灯片导出、自动裁剪白边、PowerPoint导出图片、WPS演示文稿处理、论文图片处理、课件素材提取、截图去白边、矢量PDF裁剪

---

## 这个工具能帮你做什么？

### 📊 处理 PPT / 幻灯片
- 直接连接正在运行的 **Microsoft PowerPoint** 或 **WPS 演示文稿**
- 导出当前页或全部幻灯片，自动去除周围白边
- 支持 **Windows** 和 **Mac** 系统
- 完美保留动画截图、图表、SmartArt 等复杂元素

### 📄 处理 PDF 文档
- 裁剪 PDF 页面的白边，输出仍为 **矢量 PDF**，不损失画质
- 学术论文插图、教材扫描件、电子书页面都能处理
- 支持批量处理整本 PDF 的所有页面
- 可转换为 SVG 矢量格式，方便在网页或设计软件中使用

### 🖼️ 处理图片文件
- 支持 **PNG、JPG、JPEG、BMP、TIFF、WebP、GIF** 等常见格式
- 批量选择多张图片一次性处理
- 网页截图、软件界面截图、扫描件去白边
- 产品图片、证件照、素材图批量裁剪

### 🎯 智能白边检测
- **智能模式**: 综合分析亮度、颜色变化、边缘特征，适合绝大多数场景
- **简单模式**: 仅基于亮度阈值，处理速度最快，适合纯白背景
- **边缘敏感模式**: 对浅色内容更敏感，避免误裁浅色图形

### 📦 多种输出格式
- **矢量格式 (PDF/SVG)**: 保持原始画质，无限放大不模糊，适合印刷出版
- **无损位图 (PNG/TIFF)**: 高质量图片，适合网页、文档插图
- **压缩位图 (JPEG/WebP)**: 文件体积小，适合网络分享

## 功能特点

- **多来源支持**: PowerPoint (Windows/Mac)、WPS演示文稿、PDF 文件、图片文件 (PNG/JPG/BMP/TIFF/WebP/GIF)
- **智能检测**: 三种检测模式适应不同场景，可调节阈值和敏感度
- **批量处理**: 一次处理多页 PPT/PDF 或多个图片文件，大幅提升效率
- **多格式输出**: PDF、SVG (矢量无损)、PNG、TIFF (位图无损)、JPEG、WebP (位图压缩)
- **参数可调**: 白色阈值、检测敏感度、边缘留白、输出DPI均可自定义
- **高性能**: 大图自动缩放检测，处理速度快
- **跨平台**: 支持 Windows 和 macOS
- **隐私安全**: 纯本地运行，文件不会上传到任何服务器

## 参数详解

### 来源类型

| 类型 | 说明 |
|------|------|
| PowerPoint | 连接当前打开的 PPT/WPS 演示文稿，可处理当前页或全部页 |
| 本地文件 | 选择 PDF 或图片文件，支持批量选择多个文件 |

### 检测模式

| 模式 | 原理 | 速度 | 适用场景 |
|------|------|------|----------|
| 智能模式 | 综合分析亮度、颜色变化、边缘梯度 | 中 | 通用场景，推荐使用 |
| 简单模式 | 仅检测像素亮度是否超过阈值 | 快 | 背景纯白、内容颜色深 |
| 边缘敏感 | 侧重边缘梯度检测 | 中 | 内容颜色浅、接近白色 |

### 白色阈值 (200-255)

控制什么亮度的像素被认为是"白色背景"。

| 数值 | 效果 | 说明 |
|------|------|------|
| 255 | 只裁纯白 | 只有 RGB(255,255,255) 才被当作背景 |
| 250 | 推荐值 | 裁掉纯白和接近纯白的区域 |
| 235 | 裁浅灰 | 浅灰色区域也会被裁掉 |
| 200 | 激进裁剪 | 较深的灰色也被当作背景裁掉 |

### 敏感度 (5-50)

控制对内容边缘的敏感程度，影响智能模式和边缘敏感模式的检测结果。

| 数值 | 效果 | 说明 |
|------|------|------|
| 5-10 | 裁剪激进 | 只保留非常明显的内容，边缘可能被裁掉 |
| 15-20 | 平衡 (默认) | 适合大多数情况 |
| 30-40 | 保守 | 保留更多边缘细节，适合浅色内容 |
| 45-50 | 非常保守 | 几乎不裁剪模糊边缘 |

### 边缘留白 (像素)

裁剪后在内容四周额外保留的空白像素。

- **0**: 紧贴内容边缘
- **2-5**: 推荐值，留一点呼吸空间
- **10+**: 较宽的边距

### 输出格式

| 格式 | 类型 | 特点 |
|------|------|------|
| PDF | 矢量 | 保持原始画质，可无限放大，适合打印和文档 |
| SVG | 矢量 | 网页友好，可编辑 |
| PNG | 无损位图 | 支持透明，文件较大 |
| TIFF | 无损位图 | 专业印刷，支持多页 |
| JPEG | 有损位图 | 文件小，适合照片 |
| WebP | 有损位图 | 文件最小，现代格式 |

### DPI (72-600)

输出位图 (PNG/TIFF/JPEG/WebP) 的分辨率。

| 数值 | 用途 |
|------|------|
| 72 | 屏幕显示 |
| 150 | 一般用途 |
| 300 | 打印质量 (推荐) |
| 600 | 高清印刷 |

> 注：PDF 和 SVG 是矢量格式，DPI 设置不影响其输出质量。

## 常见问题

### 内容被错误裁剪？

1. 降低「白色阈值」(如 250 → 235)
2. 提高「敏感度」(如 15 → 30)
3. 切换到「边缘敏感」模式
4. 增加「边缘留白」

### PPT 连接失败？

- 确保 PowerPoint 或 WPS 已打开并有文档
- Windows 需要安装 pywin32
- Mac 需要授权终端控制 PowerPoint

### 处理速度慢？

- 切换到「简单」模式
- 降低输出 DPI
- 大图会自动缩放检测，无需手动处理
